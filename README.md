### Work practice: JSXGraph visualizations

The objective of this work practice period was to create educational visualizations and simulations using the JSXGraph library, with written explanations and exercises to accompany them. The topics are mostly centered around statistics, with data and example scenarios drawn from biological sciences, but some are more focused on visualizing basic concepts in biology. The target audience, however, isn't biology students, but rather engineering students as well as younger students in earlier grades: most of the text and concepts should be understandable even to people with minimal biology knowledge. 

The texts accompanying the visualizations are mostly written in Finnish. The suggested exercises are intended to be added to Moodle (or another learning platform) with the correct answers revealed to the student after answering. Some exercises could be implemented as automatically graded multiple choice questions while others are open-ended. 

index.html contains an organized list of visualizations and simulations created during the practice. The repository contains some additional files, but those missing from the index list are generally unfinished or were used only for testing.
